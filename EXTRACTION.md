# Extraction manifest (deprecated)

This repository is the **canonical home** for shared platform code. It is no longer an extraction checklist from a single product.

Use instead:

- **[docs/PLATFORM.md](docs/PLATFORM.md)** — what each package owns and what belongs in consumer apps
- **[docs/CONSUMING.md](docs/CONSUMING.md)** — install and upgrade
- **[docs/consumer-integration.md](docs/consumer-integration.md)** — wiring platform packages in your application

Product-specific source maps, migration notes, and domain workflows live in **consumer repositories** (for example LMS-AI under that project’s own documentation).
